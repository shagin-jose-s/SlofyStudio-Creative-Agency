# SlofyStudio® — Premium Creative Agency Website (v2.0)

A multi-page, responsive React + Vite creative agency website template with premium dark art direction, custom CSS visual treatments, page transitions and mobile navigation.

## Requirements
- Node.js 18+ (LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Pages
- Home
- Work + individual project detail pages
- Services
- Studio
- Contact

## Customize
- `src/data.js` — project, service and process content.
- `src/pages/` — page content.
- `src/components/` — reusable navigation, footer, project card and section intro.
- `src/styles.css` — all design tokens, layout and responsive breakpoints.
- Replace sample portfolio projects with real approved work.
- Replace `hello@slofystudio.com` in Contact.jsx and Footer.jsx with your real contact email.

## Important
This is a frontend template. It does not include a CMS, backend, authentication, database, or email service. The contact form opens the visitor's default email application via `mailto`; connect a form service or backend for server-side submissions. Portfolio projects are illustrative sample content, not claims of completed client work. Google Fonts are loaded remotely.

## Stack
React, Vite, React Router, Framer Motion, Lucide React, CSS.
